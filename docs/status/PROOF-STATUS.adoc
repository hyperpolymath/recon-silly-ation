When an Agda source lands, it is checked with
`agda --safe --without-K --cubical-compatible` (PROOF-POLICY §2.1; the
invocation `scripts/check-proofs.sh agda` uses), its import cone recorded
(§1.1), and each recheck leg's route (`transported`, `re-proved`) and §2.2
correspondence state added here. Grades are derived from receipts, never
written by hand.
