The proof-status file for this repository, under
`hyperpolymath/standards` `3-practice/PROOF-POLICY.adoc` (prover mapping,
§5 status vocabulary, §8 Proof Witness Grades) and
`docs/README-EXPLAINME-STANDARD.adoc` §5 (the ledger format). This file is
canonical; the table at `EXPLAINME.adoc#proof-ledger` is derived from it.
The obligations themselves are defined in
`docs/proposals/ULTRAPLAN-2026-10-27.adoc` §6 (R-1 to R-10).

== Census

3 rows `proven`, 2 `tested-only`, 4 `argued`, 16 `open`: 25 rows in all.
Of those, 18 are this repository's own obligations (R-1 to R-10, R-9 split
into R-9a to R-9h) and 7 are the template's mandatory obligations (ABI-1 to
ABI-5, TP-1, TP-2, from `docs/status/PROOF-NEEDS.adoc`) as they apply to
this repository's own seam. Theory obligations: 3, all `ungraded` (no Agda
source yet). This is a count of rows, not a measure of confidence
(README-EXPLAINME §5, PROOF-POLICY §8.4).
