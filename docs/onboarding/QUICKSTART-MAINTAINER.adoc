= recon-silly-ation — Quick Start for Platform Maintainers
:toc:
:toclevels: 2

== Overview

This guide records the intended packaging and maintenance surface for
recon-silly-ation, an experimental cross-document consistency reconciler. The
actual reconciliation engine and its proposed bounded ForthWall VM are not yet
implemented or proved; the commands below exercise scaffolding and must not be
treated as evidence of a distributable reconciliation runtime.

== Runtime Dependencies

Zig 0.16.0 toolchain (build-time); a WASM-capable runtime at execution time.
Idris2 is only needed if regenerating the ABI headers from `abi.ipkg`.

== Build from Source

[source,bash]
----
git clone https://github.com/hyperpolymath/recon-silly-ation.git
cd recon-silly-ation
just build-release
----

Output: `src/interface/ffi/zig-out/`

== Packaging

=== Guix

[source,bash]
----
guix build -f guix.scm
----

=== Nix

[source,bash]
----
nix build
----

=== Container (Stapeln)

[source,bash]
----
just stapeln-export    # Generates Containerfile
podman build -t recon-silly-ation .
----

=== Manual Package

[source,bash]
----
just install --prefix=/usr/local
----

Files installed:

[cols="1,2"]
|===
| Path | Contents

| `$PREFIX/bin/`
| Executables

| `$PREFIX/share/recon_silly_ation/`
| Data files, assets

| `$PREFIX/share/doc/recon_silly_ation/`
| Documentation

| `$PREFIX/share/applications/`
| .desktop file (Linux, if GUI)

| `$PREFIX/share/man/man1/`
| Man pages
|===

== Configuration

Default config location: `$XDG_CONFIG_HOME/recon_silly_ation/config.toml`

Fallback: `$HOME/.config/recon_silly_ation/config.toml`

== Health Checks

recon-silly-ation currently has an FFI/WASM scaffold, not an operational
ForthWall library or standalone reconciliation executable, so there is no
`just run`. The following commands check only the present scaffold:

[source,bash]
----
just doctor            # Full diagnostic
just test              # Runs the Zig FFI test suite (zig build test)
----

== Updating

[source,bash]
----
git pull
just build-release
just install --prefix=/usr/local
----

Or via OPSM: `opsm update recon_silly_ation`

== Multi-Instance Deployment

For deploying multiple instances (e.g., different users or tenants):

[source,bash]
----
just install --prefix=/opt/recon_silly_ation-instance1 --config=/etc/recon_silly_ation/instance1.toml
just install --prefix=/opt/recon_silly_ation-instance2 --config=/etc/recon_silly_ation/instance2.toml
----

Each instance has isolated config, data, and logs.
